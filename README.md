# College Choices Nepal

A free, Nepal-localized, trust-first web app that helps +2 (12th-grade) Science students answer:
**what career, what college, what next?**

Built on verified public data with honest abroad-vs-Nepal framing (no propaganda). Schema is
stream-agnostic so Management/Commerce slots in later.
